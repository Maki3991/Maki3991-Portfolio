# 视觉判断板 v0.1

## 目的

`design-system-foundation-v0.1.md` 负责说明“哪些变量必须先定”；这份文件负责把其中需要人判断的参数变成可直接比较的视觉候选。

不要先从 `#hex`、`px` 或对比度数字判断。先看真实内容在候选中的整体感觉，再把选择写回设计系统。

## 直接打开

[打开视觉判断板](../../../output/design-system-foundation-v0.1/index-visual.html)

如果浏览器直接打开本地 HTML 时资源行为异常，可在仓库根目录启动静态服务器后访问同一文件。这个板只使用现有个人资料、英语自媒体项目和 V028 作品的简化真实内容，不连接生产页面。

## 判断方式

按四轮进行，每轮只判断一个变量：

1. **色彩**：冷白、略暖纸张、高对比冷灰。看你是否愿意长期面对它，以及正文和弱化文字是否舒服。
2. **字体**：中性无衬线、安静编辑感、大标题主张。看标题像不像你，正文是否愿意持续读。
3. **密度**：宽松、平衡、紧凑。看首页既要介绍自己又要导航项目时，哪种节奏最自然。
4. **形状**：克制边界、柔和表面、硬朗索引。看圆角与阴影是否帮助分组，还是把页面变成模板。

每一轮可以：

- 点击一个候选，记录明确选择；
- 在文本框里写自由反馈，包括“都不喜欢”；
- 写混合方案，例如“色彩 A、字体 C、但 C 的标题小一点”；
- 最后在总体反馈区补充整体气质或设备差异。

点击“导出我的判断”后，得到 `foundation-decision-v0.1.md`。这份导出文件才是下一步回写参数的输入，不会自动修改生产 CSS。

## 当前预设推荐

在没有你的视觉反馈前，暂时建议以 **A / A / B / A** 作为工作假设：

- 色彩 A：延续当前冷静的蓝灰索引方向；
- 字体 A：最稳定、最易维护的无衬线系统；
- 密度 B：兼顾介绍、项目和长期阅读；
- 形状 A：避免商业模板感，保留工作台性质。

这只是默认起点，不是替你做出的最终决定。你的点击和自由文本优先级更高。

## 尚不能由代码判断的部分

- 你是否觉得冷白还是纸张底色更像自己的长期工作环境；
- 标题应该克制、编辑化，还是有更强的主张；
- 你对“宽松”与“信息效率”的实际偏好；
- 轻阴影和圆角是否让你感到亲近，还是觉得像模板；
- 不同显示器、浏览器缩放和移动端上，哪一套仍然舒服。

这些问题由视觉板收集，而不是继续堆更多数字。
