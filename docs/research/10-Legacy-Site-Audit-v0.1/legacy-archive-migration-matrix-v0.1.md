- Projects 和 Works 合并为新版 Archive；

- 这些视频进入自媒体项目详情页；
- Audibooker 不进入 Home，也不在首批 Archive 公开；

- Portfolio 副标题不迁移；
- In it for the long haul. 只作为长期更新态度的候选辅助表达，不是完整职业定位。

### 方法和过程材料

“抖音爆款开头复盘”更像方法 / 过程材料，不必和单条视频平级。默认建议放入 Maki English 详情中的：

- 内容方法；
- 复盘样例；
- 过程证据。

它是否单独成为 Archive 条目，等内容量增加后再决定。

### LPT 交付材料

“LPT 私域英语直播交付”默认作为 LPT 详情中的交付记录，而不是另一个一级项目。只有当它发展成独立、可公开、可复盘的案例时，才考虑独立归档。

### 音乐

“Things They Left Behind” 是真实且有辨识度的个人创作资产。旧版已经有音乐分类，但目前不把它自动视为首批 Archive 的必选项。它可以作为：

- 首批 Archive 的独立创作条目；或
- 第二批加入的长期创作条目。

这是唯一建议 Maki 再确认的分类归属问题，不影响先整理前四个候选。

## 5. 建议的新 Archive 条目关系

新版内容模型至少需要表达下面的关系：

| 关系 | 示例 |
| --- | --- |
| 条目类型 | project、experience、creation、work |
| 项目包含作品 | Maki English 包含 v028、v091 等 |
| 条目包含证据 | 账号截图支持播放量主张 |
| 状态 | active、completed、paused、private、draft |
| 公开范围 | public、redacted、private |
| 时间 | 开始时间、结束时间或持续更新 |
| 外部链接 | 正式链接、待补充、无外链 |

不要求第一版马上实现所有筛选器，但这些字段应在内容记录层预留，避免以后为新增板块重新设计数据结构。

## 6. 不迁移的旧版表现形式

- Projects 和 Works 两个并列一级入口；
- 旧版所有项目一次性长展开；
- Works 以“英语自媒体 11 个作品”作为首页式主叙事；
- 独立 Proof 墙；
- 暖色背景、衬线标题、圆角卡片、半透明 blur；
- Portfolio 副标题；
- Audibooker 的公开展示；
- 没有真实链接的占位卡片。

## 7. 迁移顺序

1. 先确认四个首批候选的事实和公开边界；
2. 为四个候选建立内容记录；
3. 为 Maki English 建立“项目—代表作品—证据”的嵌套关系；
4. 为 LPT、AutoCoder、AdventureX 建立各自的经历字段；
5. 再根据真实内容决定 Archive 总览卡片需要显示哪些字段；
6. 最后实现 Archive 页面和详情页。
