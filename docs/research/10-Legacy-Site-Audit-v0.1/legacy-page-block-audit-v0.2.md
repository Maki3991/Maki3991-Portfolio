## 当前新版 Home 内容边界

Home 暂定顺序：

1. Hero / 身份介绍；
2. Live Index / 当前身份、地区、方向、开放机会；
3. Current Workbench / 当前正在做的事情；
4. Selected Work / 自媒体等少量代表性项目；
5. Contact / 微信和邮箱。

Home 不承担：

- 十项数据指标；
- 三条视频的逐条展示；
- 全部社交账号；
- Current Questions 独立区块；
- Open Loops 独立区块；
- Currently Reading 独立区块；
- Archive 全部条目。

## Maki 现在只剩一个非阻塞开放问题

请以后补充：

> 我希望别人通过这个网站认识到我是一个怎样的人？

目前没有灵感是有效状态，不需要为了通过审计而编造一句定位。可以先使用真实身份事实，等 Projects、Works 和 About 审计完成后再回看。

## 不需要 Maki 重新填写的决定

- Audibooker 从 Home 移除并进入 Archive 候选；
- 首页移除数据墙；
- 视频统一作为自媒体项目详情内容；
- Home 展示微信和邮箱；
- 独立 Contact 展示全部社交账号。
