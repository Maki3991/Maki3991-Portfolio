# Legacy Site Audit Plan v0.2

状态：当前有效 / 执行版  
来源：[legacy-site-audit-plan-v0.1.md](./legacy-site-audit-plan-v0.1.md) 与 Maki 修改后的 Home decision digest  
说明：v0.1 的审计流程和证据规则继续有效；本版本覆盖其中已经被 Maki 新决定的内容，不再重复向 Maki 提问。

---

## 1. 当前已确认的内容决定

### Home

Home 暂定顺序：

1. Hero / 身份介绍；
2. Live Index / 当前身份、地区、方向、开放机会；
3. Current Workbench / 当前正在做的事情；
4. Selected Work / 少量代表性项目；
5. Contact / 微信和邮箱。

Home 不加入：

- 完整数据墙；
- 三条视频的单独卡片；
- 全部社交账号；
- Current Questions、Open Loops、Currently Reading 独立区块；
- Archive 全部条目。

持续更新是网站原则，但不是 Home Hero 的最终个人定位。

### Archive

Projects 和 Works 统一为 Archive。

当前首批候选：

- Maki English 自媒体；
- 英语教育产品与社群交付；
- AutoCoder 实习经历；
- AdventureX 黑客松。

Audibooker：

- 从 Home 移除；
- 进入新版 Archive 候选；
- ~~是否作为首批公开条目，等 Archive 内容和证据核验后决定~~，暂不公开。

### 自媒体内容

Home 最多把自媒体作为一个 Selected Work 项目。

具体视频、播放数据、平台截图和作品链接：

- 不在 Home 逐条展开；
- 进入自媒体项目详情页；
- 详情页再决定视频排序和证据呈现。

### Contact

- Home：微信和邮箱；
- 独立 Contact：参考旧版 Contact，展示全部社交账号；
- 微信是主要入口，邮箱作为备用入口；
- 不让二维码成为唯一联系方法。

---

## 2. Maki 的当前角色

Maki 在本次审计中只需要承担三类判断：

1. 事实判断：内容是否准确；
2. 个人判断：内容是否还代表现在的自己；
3. 公开判断：哪些经历、数据、账号和证据可以公开。

已经完成的判断不再重复：

- Audibooker 的 Home 位置；
- Home 数据墙是否保留；
- 视频是否在 Home 单独展示；
- Home 联系方式；
- Home 是否增加独立的 Reading 或 Current Questions 区块。

仍然开放但不阻塞：

- Home Hero 的个人定位；
- Portfolio 副标题；
- Audibooker 是否资料充分到可以进入首批 Archive；
- 自媒体详情页数据的时间范围和平台口径；
- 旧页面中哪些文案最终删除或重写。

## 3. Agent 接下来的实际工作

### 阶段一：Projects / Works 运行时审计

检查：

- 页面顺序；
- 项目和作品卡片；
- 详情锚点；
- Works 分类和展开状态；
- 数据字段；
- 空状态；
- 外部链接；
- 移动端布局；
- 旧分类是否造成理解成本。

### 阶段二：Archive 迁移矩阵

对每个候选条目记录：

- 新版标题；
- 临时类型；
- 当前状态；
- Maki 的角色；
- 一句话摘要；
- 证据；
- 是否需要详情页；
- 是否进入 Home；
- 是否需要补充或匿名化；
- 下一步。

### 阶段三：第一个详情页

优先审计英语教育产品与社群交付：

- 背景；
- 交付范围；
- Maki 的职责；
- 最终结果；
- 证据；
- AI 参与边界；
- 可公开程度；
- 详情页素材缺口。

### 阶段四：反馈交付

Agent 每一轮只交付：

- 一页摘要；
- 关键截图；
- 迁移表；
- 必须由 Maki 判断的问题。

Maki 不需要读完所有源码，也不需要重复填写已经在 Home digest 中解决的问题。

---

## 4. 下一道闸门

继续 Projects / Works 审计之前，只需要知道：

- Home 的当前决定已经生效；
- 首批 Archive 的候选范围；
- Maki English 的视频只进入详情页；
- Audibooker 不出现在 Home；
- 微信和邮箱出现在 Home；
- Hero 定位暂时开放，不阻塞。

Projects / Works 审计完成后，再由 Agent 汇总出：

- Archive Content Model v0.1；
- 首批 Archive 条目草稿；
- 第一个详情页内容骨架；
- Site Content Outline v0.2 的更新建议。

此阶段仍不修改生产代码。
