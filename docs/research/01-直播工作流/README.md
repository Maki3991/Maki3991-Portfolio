# 01-直播工作流

## 这组资料是做什么的

保存从用户提供的直播分享稿中压缩出的“用 AI 从零搭建个人网站”的工作流和经验。它是本项目的流程参考，不是个人资料，也不是最终的网站需求文档。

## 文件说明

| 文件 | 用途 | 状态 |
|---|---|---|
| [个人网站重建_AI工作流直播摘要.md](./个人网站重建_AI工作流直播摘要.md) | 直播内容的压缩摘要，供 Agent 在后续阶段调用 | 当前有效 |

原始逐字稿已按用户决定删除；当前以这份摘要和用户后续明确的决策为准。若二者冲突，以用户最新决策为准。

## 使用时机

当用户问“按照直播分享者的流程，下一步应该做什么”或需要解释本项目工作流时，先读本摘要；不要要求用户重新阅读或整理逐字稿。
