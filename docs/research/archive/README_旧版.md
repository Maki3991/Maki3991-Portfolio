## 文件顺序

1. [主研究报告](./个人网站长期重建_国际参考资源研究报告.md)：研究目标、候选池、评分、模式总结和下一阶段路线。
2. [候选对比表](./portfolio_research_candidates.md)：按结构、组件库、设计过程和页面模式整理的候选与评分。
3. [证据账本](./evidence_ledger.md)：每个结论对应的公开来源、证据等级和边界。
4. [依赖/许可证/采用建议](./深度核验_依赖许可证与采用建议.md)：重点候选的技术事实和采用取舍。
5. [真实构建核验](./构建核验记录_候选模板.md)：隔离克隆后的安装、build、警告和失败原因。
6. [下一轮上下文](./next_thread_context.md)：可以直接喂给新 Agent 的目标、限制和下一步。

## 当前推荐阅读顺序

如果下一轮只想快速接续：先读 `next_thread_context.md`，再读 `构建核验记录_候选模板.md`；如果需要理解评分依据，再读主报告和证据账本。

## 研究边界

- 所有外部材料均来自公开页面、公开仓库或公开社区讨论。
- 社区评论只作为经验线索，不作为客观质量证明。
- 仓库 README 的 Lighthouse、用户数、性能等数字属于作者自述，除非另有独立实测，不进入客观结论。
- 本阶段不确定最终栏目、不确定最终配色、不修改网站实现，也不提前做视觉定稿。
