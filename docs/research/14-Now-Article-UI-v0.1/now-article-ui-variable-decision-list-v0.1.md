# Now Article UI 变量决策清单 v0.1

状态：P1 决策已记录 / P1-02 正在试用 980px

本清单用于区分：

- 哪些规则已经由 Foundation 锁定；
- 哪些 Now 页面变量需要单独设计；
- 哪些变量需要做 5 个可视化选项；
- 哪些变量等真实文章出现对应内容后再决定。

“需要 5 选 1”只适用于尚未确定且会明显改变视觉体验的变量，不适用于每个 CSS 属性。

## 2. 第一轮必须单独决策

这些变量应使用当前真实测试稿制作 A/B/C/D/E 五个视觉方案。

| ID | 变量 | 需要回答的问题 | 5 选 1 | 状态 |
|---|---|---|---|---|
| P1-01 | 页面标题与文章标题关系 | `Now` 作为页面标题，正文直接开始，不再设置日期文章标题 | D：Now 页面标题 + 正文直接开始 | 已选择 |
| P1-02 | 文章内容宽度 | 保持 Now 标题使用全站主轨道，正文改用可读内容轨道，观察长段落是否更舒服 | D：可读内容轨道 / 980px | 待最终确认 |
| P1-03 | 日期呈现 | 不把日期作为 H1 或独立日期模板；作者在正文中自由写更新句 | 不做 5 选 1：正文自由表达 | 已确定 |
| P1-04 | 文章边界 | 正文与画布之间不设置明显容器边界 | A：开放式正文 | 已选择 |
| P1-05 | 正文密度 | 行高、段落间距和标题间距保持平衡 | C：平衡 | 已选择 |
| P1-06 | 文章内标题尺度 | 当前不设置独立文章 H1；未来出现标题型文章时再决定层级和换行 | 否 | 条件性待决策 |
| P1-07 | 小标题层级 | `h2`、`h3` 与正文之间的视觉层级是否足够清楚？ | 是 | 待决策 |
| P1-08 | 分隔线策略 | Markdown `hr` 是否保留，使用什么强度，是否与页面结构线区分？ | 是 | 待决策 |
| P1-09 | 链接样式 | 下划线、accent 色、箭头、hover 和外部链接如何表达？ | 是 | 待决策 |
| P1-10 | 列表样式 | 列表缩进、项目符号、编号和连续条目间距如何处理？ | 是 | 待决策 |
| P1-11 | 引用样式 | 引用是否使用左侧线、文字色变化或开放式缩进？ | 是 | 待决策 |
| P1-12 | 文章底部出口 | 文章结束后只回到 Home，还是保留更新时间、下一步或相关入口？ | 是 | 待决策 |
| P1-13 | 移动端文章节奏 | 移动端左右边距、标题换行和段落宽度如何收缩？ | 是 | 待决策 |
| P1-14 | 内容与页面末尾关系 | Footer、返回 Home 和文章末尾之间需要多大的收束感？ | 是 | 待决策 |

## 3. 内容合同变量

这些变量不一定通过视觉 5 选 1 解决，但必须在文章 UI 进入生产前明确。

| ID | 变量 | 当前建议 | 状态 |
|---|---|---|---|
| CONTENT-01 | `date` frontmatter | 必填，使用 `YYYY-MM-DD`，负责排序 | 已确定 |
| CONTENT-02 | 文件名 | 建议使用 `YYYY-MM-DD.md`，但以 frontmatter 为准 | 待确认 |
| CONTENT-03 | 首个 H1 | 不要求日期 H1；文章直接从正文开始，作者可在正文中自由写更新句 | 已确定 |
| CONTENT-04 | 最新文章判定 | 按 `date` 倒序，只渲染第一篇 | 已确定 |
| CONTENT-05 | 同日多篇文章 | 暂不支持；需要时再增加时间或显式 order | 待决策 |
| CONTENT-06 | 缺少日期 | 构建失败并给出明确错误，不能静默发布 | 待确认 |
| CONTENT-07 | 空文章 | 显示诚实空状态或阻止构建 | 待确认 |
| CONTENT-08 | Markdown 范围 | 标题、段落、列表、链接、强调、分隔线先作为基础范围 | 已确定 |
| CONTENT-09 | 原始 HTML | 是否允许在 Markdown 中直接写 HTML | 待决策 |
| CONTENT-10 | 图片 | 图片路径、宽度、圆角、说明文字和移动端处理 | 条件性待决策 |

## 4. 只有真实内容出现后才决策

以下项目暂时不做空想式设计。等文章真的需要时，再单独建立变量选项：

- 图片和图片说明；
- 图集；
- 引用块；
- 代码块和代码语言标签；
- 表格；
- 脚注；
- 数学公式；
- 视频或外部嵌入；
- 音频；
- 附件下载；
- 目录或文章内锚点；
- 文章搜索；
- 分享按钮；
- 打印样式；
- 阅读进度；
- 多文章导航；
- 公开历史版本。

## 6. 当前推荐决策顺序

当前未完成的变量按下面顺序推进：

1. P1-02 文章内容宽度的真实阅读确认；
2. P1-08 分隔线策略；
3. P1-09 链接样式；
4. P1-10 至 P1-14 的正文细节和移动端收束。

先确定页面骨架，再确定正文细节，最后处理只在真实内容中出现的特殊元素。
