# Component Lab v0.2：剩余 39 个组件选择表

状态：草稿，等待 Maki 选择

更新时间：2026-09-15

## 使用方法

这份文档只对应剩余的 39 个组件：39 × 5，共 195 个方案；不覆盖已经完成的前 21 个高影响组件。

每个组件按照 `output/component-lab-remaining-v0.1/index.html` 中实际出现的顺序排列。浏览对应 Lab 区块后：

1. 通常只把一个方案的 `[ ]` 改成 `[x]`；
2. 如果明确要保留不同方案的不同部分，只勾选“融合”，并在“融合说明”中写清楚分别取什么；不要同时把多个 A–E 方案当成最终选择；
3. 还没有判断时勾选“暂不决定”，不要为了填表强行选择；
4. “评论、保留规则、排除内容、第一版处理”是给之后 Agent 的执行依据；
5. X 组属于后续页面与功能候选，即使选中视觉方案，也不代表它必须进入第一版。

### Lab 入口

- [打开剩余 39 × 5 Lab](../../../output/component-lab-remaining-v0.1/index.html)
- [查看前 21 个选择表](./component-selection-decisions-v0.2-21x5.md)
- [查看 39 × 5 组件说明](./component-lab-remaining-39x5.md)

### 五个方案族

- A — Editorial Rail：编号、左侧轨道和编辑式秩序；
- B — Quiet Grid：柔和表面、留白和安静网格；
- C — Dense Index：等宽元数据、高密度和系统索引；
- D — Split Signal：高对比强调面、状态和行动信号；
- E — Open Field：减少容器，让内容在开放留白中建立关系。

### 记录规则

- 这里选择的是单个组件的结构、密度和交互倾向，不是一套完整主题；
- 亮色仍然是第一版主要开发对象，暗色只需保持语义对应；
- 不喜欢的部分要明确写进“排除内容”，方便后续融合时排除；
- 第一版不需要使用全部 39 个组件，尤其是 X 组可以明确写“暂不进入”；
- 选择完成后，结果会和前 21 项一起汇总为 Component Contract，不直接复制 Lab CSS 到 `src/`。
