# Component Lab v0.2：21 个高影响组件选择表

状态：草稿，等待 Maki 选择

更新时间：2026-09-15

## 使用方法

这份文档只对应 Component Lab v0.2：21 × 5，暂不包含后续的 39 个候选组件。

每个组件按 HTML 中实际出现的顺序排列。浏览对应 Lab 区块后：

1. 通常只把一个方案的 [ ] 改成 [x]；
2. 如果想保留不同方案的不同部分，勾选“融合”，并在“融合说明”里写清楚；
3. 还没有判断时勾选“暂不决定”，不要为了填表强行选择；
4. “评论、保留、排除、第一版处理”是给之后 Agent 的执行依据。

### 五个方案族

- A — Editorial Rail：编号、左侧轨道和编辑式秩序；
- B — Quiet Grid：柔和表面、留白和安静网格；
- C — Dense Index：等宽元数据、高密度和系统索引；
- D — Split Signal：高对比强调面、状态和行动信号；
- E — Open Field：减少容器，让内容在开放留白中建立关系。

### 记录规则

- 这里选择的是某个组件的结构和视觉倾向，不是一套完整主题；
- 亮色仍然是第一版主要开发对象；
- 不喜欢的部分要明确写出来，方便后续融合时排除；
- X 组未来功能不在本文件中处理。

## 选择记录

选择方式：把选中的方案从 [ ] 改成 [x]。通常每个组件只选一个；如果是融合方案，勾选“融合”并填写说明。
