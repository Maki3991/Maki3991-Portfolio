# Maki 自我介绍网站 AI 设计 PRD v3：页面结构版

## 1. 项目一句话

请设计一个中文个人自我介绍与作品集网站，让第一次认识 Maki 的人快速知道：

- Maki 是谁
- Maki 做过哪些真实事情
- 哪些数据和作品能证明这些事情
- Maki 关注什么方向
- 如何自然地联系 Maki

## 2. 核心定位

网站定位：

> 一个给同频的人看的个人作品档案，用真实成果、项目经历和持续更新的记录，让别人知道 Maki 不是空白简历，而是已经开始在真实世界里做事的人。

希望用户看完后的感受：

- 这个人确实做过一些事。
- 英语自媒体是目前最强的可信度证据。
- 这个人有内容判断、执行力、学习力和表达能力。
- 这个人不只是做运营，也对 AI、教育产品、音乐、创作和学习系统感兴趣。
- 这个人值得继续认识，而不是被立刻“销售转化”。

## 3. 当前内容主线

当前网站应该以“英语自媒体”作为最重要主案例。

内容权重建议：

1. 主线：Maki 羽轩英语自媒体
2. 第二主线：LPT 英语产品运营 / 英语直播交付
3. 支撑线：AI 辅助个人作品集
4. 侧线：音乐作品、写作、AI 实验、耳机/设备/生活兴趣等

## 4. 页面数量建议

推荐第一版生成 7 个页面。

其中 5 个是一级页面：

1. Home 首页
2. Projects 项目
3. Works 作品档案
4. About 关于
5. Contact 联系

另外 2 个是项目详情页：

6. Project Detail：Maki 羽轩英语自媒体
7. Project Detail：LPT 英语产品运营

暂时不建议把“音乐”“耳机”“乱七八糟的兴趣”做成独立导航页面。它们应该先作为 Works 或 About 里的轻量内容出现。等未来某个兴趣形成明确作品、数据、项目过程或可展示成果，再升级成独立项目页。

如果 AI 工具不方便生成多页面，可以把 7 个页面做成一个完整原型里的 7 个 frame。

## 5. 全站导航

导航项：

- 首页
- 项目
- 作品
- 关于
- 联系

导航要轻，不要像企业官网，也不要像课程销售页。可以 sticky，但不要厚重。

- 空泛大词堆叠

当前站点已有风格偏浅米色背景、深绿强调、宋体/衬线标题、8px 卡片圆角。新版可以继承“温和、克制、可信”的感觉，但版式要更灵活，减少卡片堆叠。

## 15. 文案规则

文字要具体、短、清楚。

优先写：

- 做过什么
- 我负责什么
- 数据是什么
- 这说明什么
- 下一步还要补什么

不要写：

- 打造个人影响力
- 赋能内容生态
- 构建长期价值闭环
- 探索无限可能
- 用热爱驱动未来
- AI-Powered Workflow
- 提升效率 300%

## 16. 移动端要求

移动端要优先保证阅读体验。

要求：

- 首屏文字不要太长
- 数据卡片不要挤成一行
- 项目详情页按单列阅读
- 二维码不要挤压正文
- Works 卡片可以纵向排列
- 所有按钮文字不能换行溢出
