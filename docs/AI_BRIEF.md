# Maki 个人作品集网站 AI Brief

## 你要帮我做什么

请帮我设计并实现一个长期可维护的个人作品集网站。

这个网站不是一次性的求职页面，也不是单纯的简历附件，而是我的长期个人主页。它要让第一次认识我的人快速理解：

- 我是谁
- 我长期在做什么
- 我有哪些真实作品和数据
- 我有哪些能力值得被信任
- 如何进一步联系我或查看我的账号

网站第一版可以简单，但结构要适合长期扩展。

## 我的基本背景

我叫 Maki / Maki 羽轩，是一名国际政治本科生，同时长期做英语学习内容、自媒体账号运营、英语产品交付和个人学习系统搭建。

我目前比较重要的身份包括：

- 英语内容创作者
- 自媒体账号主理人
- 内容运营 / 新媒体运营实习候选人
- 英语学习社群与产品交付参与者
- AI 工具使用者
- 长期学习者和表达者

我的长期关注方向：

- 英语学习方法
- 内容表达
- 自媒体运营
- 教育产品
- AI 辅助创作与个人生产力
- 学习系统
- 写作、研究和知识整理
- 音乐创作

## 网站核心定位

这个网站应该是我的“可信度主页”。

它不是为了把我包装得很厉害，而是把我已经做过的事情清楚、可信、可验证地展示出来。

它应该给人的感觉是：

- 清晰
- 可信
- 有真实作品
- 有复盘能力
- 有长期积累感
- 不浮夸
- 不像模板站

## 视觉风格

整体风格应该克制、干净、有内容感。

不要做成营销落地页，也不要做成花哨的个人 IP 海报。

建议风格：

- 白底或浅色底为主
- 少量深色强调
- 排版清晰
- 重点突出数据和作品
- 卡片可以使用，但不要满屏堆卡片
- 移动端阅读体验要好
- 不要使用过多渐变、装饰图形或夸张动画

适合的关键词：

- editorial
- clean
- portfolio
- content archive
- evidence-based
- calm
- readable

## 第一版范围

第一版不要做太复杂。

建议先实现：

- 首页
- 作品集页
- 项目页
- 关于页
- 联系方式

第一版可以先用静态数据，不需要后台。

优先级：

1. 信息结构清楚
2. 移动端可读
3. 作品链接可点
4. 数据可信
5. 后续容易新增作品

暂时不需要：

- 登录系统
- 数据库
- 复杂动画
- CMS
- 评论区
- 搜索功能

- 不夸大
