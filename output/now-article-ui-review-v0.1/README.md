# Now Article UI Review Preview v0.1

这是一个只用于 Now 文章 UI 决策的本地预览，不属于生产网站。

直接打开 index.html 即可。

## 页面保留的功能

- 选择当前要判断的视觉要素；
- 选择 A、B、C、D、E 方案；
- 上一个 / 下一个视觉要素；
- 使用键盘 A–E 和左右方向键；
- 打开自由反馈并保存到当前浏览器本地。

## 页面主动删去的内容

- 网站正式导航；
- Lab 介绍文案；
- 统计数字；
- 搜索和筛选；
- 组件目录；
- 与当前视觉判断无关的装饰性卡片。

第一轮保留 P1-01、P1-02、P1-04、P1-05 四个视觉变量；P1-03 已转为内容合同。每次只显示一个变量的一篇真实测试文章。
