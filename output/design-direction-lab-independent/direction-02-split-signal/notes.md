# 02 · Split Signal / 分栏信号

## 视觉核心假设

如果首屏必须在几秒内让人记住“是谁 + 做过什么 + 有什么证据”，就把身份叙事与代表作品拆成两个同等重要的屏幕区域。左侧承担定位和当前方向，右侧承担一件真实作品及其数据，首页像一次短而明确的 briefing。

## 结构与排印

- 构图：首屏左右分栏；左侧是大号定位，右侧是固定比例的真实作品封面和数据条。后续区块继续使用左右关系。
- 字体：压缩感强的超大无衬线标题 + 等宽微标签；蓝黑底配单一冷青强调色。
- 信息密度：中等。首屏信息集中，下面用大留白让项目和 Now 各自有清楚的入口。
- 项目 / 文章：项目以“主项目 + 代表作品”并列；Note 作为独立的大句子，不伪装成文章索引。
- 导航：桌面顶部；移动端原生展开菜单。首屏 CTA 直接跳到项目区。
- 图片 / 媒体：V028 作为首屏右侧的主证据面板，照片/封面拥有叙事优先级。
- 动效：只使用 hover/focus、短透明状态和原生锚点；没有自动轮播或转场。

## 适合长期更新的地方

每次只替换右侧代表作品或增加一个项目区块，首屏的身份与证据关系不需要重做。项目结果可以继续保持三列，但前提是每个数字都有真实来源。

## 可能的问题和风险

右侧大图会让首页较强依赖封面质量；如果未来有多个同等重要项目，需要定义“代表作”选择规则。大标题在小屏会占据较多首屏高度，需避免把联系入口推得过深。
