# Design System Foundation v0.1 视觉判断板

这是一个与 Astro 生产页面隔离的交互式选择板，用来把“色号、字号、留白、圆角”变成可直接观察和比较的候选方案。

## 打开

在仓库根目录启动一个静态服务器，然后访问：

```text
output/design-system-foundation-v0.1/index.html
```

也可以直接用浏览器打开 `index.html`；但使用本地静态服务器更接近真实页面的资源加载方式。

## 怎么判断

每一轮只比较一个变量：

1. 色彩：页面底色、正文、弱化文字、边框和强调色的性格与可读性。
2. 字体：正文、标题、元信息在真实内容中的气质、层级和阅读压力。
3. 密度：首页首屏与项目条目之间的呼吸感。
4. 形状：边框、圆角和阴影是否让页面更像个人工作台，而不是商业模板。

选择按钮记录明确选择；文本框保留自由反馈。页面底部可以导出一份 Markdown 决策记录，供后续写回研究文档。

## 当前边界

- 内容取自现有个人资料、英语自媒体项目和 V028 作品，避免用抽象占位符判断。
- 这是候选比较板，不会自动把选择写入 `src/`，也不会替代最终浏览器验收。
- “我都不喜欢”“A 的颜色 + B 的字体”等混合反馈都可以直接写入文本框。
