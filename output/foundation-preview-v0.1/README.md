# Foundation Preview v0.1

这是已选 Foundation Profile（Palette A / Typography B / Density A / Shape B）的真实内容预览，不属于 Astro 生产页面。

## 打开

直接打开同目录的 `index.html` 即可。页面包含三个连续锚点：

- Home：首屏、头像、Live Index、Current Workbench、代表项目；
- ArchiveRow：四条真实 Archive 索引记录；
- Archive Detail：Maki English 的贡献、结果、公开范围和证据。

## 本轮看什么

先看三条真实链路能否保持同一种系统语言：标题是否有 Quiet Editorial 的气质、Open Field 是否过松、Soft Surface 是否变成卡片墙、正文与弱化文字是否舒服。

本预览刻意没有提前决定 Header blur、状态色和暗色主题；这些仍在 Foundation Profile 的开放项中。
