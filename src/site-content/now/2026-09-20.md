### 个人网站迭代

受到老王前哨战的分享影响，模仿老王的方法把自己陈久的个人网站翻了出来进行 UI 更新。老王的方法简单说就是让 agent 学习设计行业乙方与甲方对齐需求的 workflow，用到自己的个人网站的设计里。最惊艳的方法——也是最耗 token 的方法——就是让 agent 梳理 62 个影响一个网站观感的组件，然后每个组件设计 5 个不同样式，总共 310 个样式，由人类来一一判断哪个好哪个不好。老王称之为 labs。

我实操了老王的方法，但不知哪一步没走对，最终网站的效果就是不如他好。同时自从模仿老王的方法后，我每日的 token 消耗量就突破了 1 亿，最高日耗量达到了 3.6 亿。

现在网站最关键的 Home、Archive 和 Now 页面差不多完工了，About 和 Contact 复用了之前的页面，还待单独修改。
